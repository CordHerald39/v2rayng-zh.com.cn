> 核验于 2026-09-20：本文基于开发者资料与发行记录整理；未完成客户端 GUI、真实订阅或设备实测。以下验收标准是操作目标，不是已跑出的测试结果。

## 一份反馈需要能重复

写清应用版本、Android 版本、设备架构、网络类型，以及执行了什么动作。将“不能用”改成“更新某个测试分组后出现哪条错误”，开发者才能判断发生阶段。

2.2.6 发行说明提到分享日志功能，但不同版本入口可能变化。使用所用版本提供的导出或分享方式，先保存到自己控制的位置，检查内容后再发送。

## 只保留相关时间段

先记下复现开始时间，再完成一次失败动作。只截取前后相关段落，保留错误前的上下文，不连续刷屏后只发最后一行。截图不能显示全部内容时优先使用脱敏文本。

| 可保留 | 应遮盖或删除 |
| --- | --- |
| 客户端与系统版本 | 完整订阅 URL 和令牌 |
| 操作顺序与时间 | 节点密码、UUID 等凭据 |
| 错误类型与必要字段名 | 私人访问记录及非必要 IP |
| 是否在另一网络复现 | 无关通知、账户信息 |

## 提交前先搜索

去原始项目 Issues 搜索版本与错误关键词，避免把已有修复当作未知问题。描述预期结果、实际结果和是否能恢复到旧设置，勿把未测的猜测写成确定根因。

开发者 Issues 用于软件问题，不是本站客服。本站文章错误应记下页面与原始资料依据，由维护者更正，不要求读者公开敏感配置。
